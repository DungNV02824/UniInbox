# zalo-personal-worker (Giai đoạn 1C — chưa làm)

Process riêng chạy thư viện **không chính thức** `zca-js` để kết nối Zalo cá nhân của nhân viên; tách khỏi api/worker để lỗi hoặc bị khóa tài khoản không ảnh hưởng hệ thống chính.
Chưa có `package.json` nên pnpm bỏ qua thư mục này. Xem mục 2.3 và Giai đoạn 1C trong `dezon-omnichannel-ai-spec.md`.
